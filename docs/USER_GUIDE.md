## 3) ขั้นตอนที่ 0 — พื้นที่รับผิดชอบ

**ต้องทำก่อนอัปโหลด Excel**  
ปุ่ม «วิเคราะห์และโหลดตาราง» จะถูกปิดไว้ จนกว่าจะกดยืนยันพื้นที่รับผิดชอบ

### 3.1 หน่วยเล็กสุด = ตำบล

- ในขั้นตั้งค่าพื้นที่ **ไม่มี** การเลือกหมู่บ้าน / หมู่ (moo)
- เลือกได้เฉพาะ **ตำบล** (ติ๊กได้หลายตำบล)
- การสุ่มหมู่จะเกิด **หลัง** วิเคราะห์ Excel สำหรับงานภาคสนามเท่านั้น

### 3.2 ขั้นตอนทีละข้อ

1. (แนะนำ) เลือก **พรีเซ็ตด่วน** → `อำเภอสีดา (นครราชสีมา)`  
   ระบบจะเติมจังหวัด / อำเภอ / ชื่อสำนักงานให้อัตโนมัติ
2. เลือก **บทบาทผู้ใช้** (ดูตารางด้านล่าง)
3. กรอก **ชื่อเจ้าหน้าที่** (ไม่บังคับ แต่ช่วยอ่านสรุปพื้นที่)
4. ตรวจว่า **จังหวัด / อำเภอ** ถูกต้อง
5. ตรวจ **ชื่อสำนักงาน** = `สำนักงานเกษตรอำเภอสีดา` (ใช้วันประชุมวันจันทร์)
6. ติ๊ก **ตำบลที่รับผิดชอบ** ในกริด  
   - เจ้าหน้าที่: เลือก 1 หรือหลายตำบล  
   - หรือกด «เลือกทุกตำบลในอำเภอ» / «ล้าง»
7. อ่านแถบสรุปด้านล่าง (เช่น `ตำบลหนองตาดใหญ่ — สุ่มหมู่ในตำบลนี้`)
8. กด **「ยืนยันพื้นที่รับผิดชอบ แล้วไปอัปโหลด Excel」**

เมื่อยืนยันแล้ว สรุปจะมีเครื่องหมาย ✓ และปุ่มอัปโหลดจะเปิดใช้งาน

> ![ภาพหน้าจอ — ยืนยันพื้นที่](../static/docs/shot-setup.png)  
> *วางภาพ Step พื้นที่รับผิดชอบที่นี่*

### 3.3 บทบาท

| บทบาทในหน้าจอ | ค่าในระบบ | พฤติกรรม |
|----------------|-----------|----------|
| เจ้าหน้าที่ประจำตำบล | `officer` | เลือก 1+ ตำบล · สุ่มหมู่ตามตำบลที่เลือก |
| เกษตรอำเภอ / หัวหน้า (ทุกตำบล) | `district_chief` | ระบบเลือกทุกตำบลให้อัตโนมัติ · **ไม่สุ่มหมู่** |
| ธุรการ (ไปกับหัวหน้า · ทุกตำบล) | `admin_clerk` | เหมือนหัวหน้า · ทุกตำบล · **ไม่สุ่มหมู่** |

**หมายเหตุ**

- เปลี่ยนบทบาท / เปลี่ยนตำบล → ต้อง **ยืนยันพื้นที่ใหม่** ก่อนอัปโหลดอีกครั้ง
- ถ้าเจ้าหน้าที่ติ๊กครบทุกตำบลในอำเภอด้วยตนเอง ระบบถือว่าเป็นโหมด «ทุกตำบล» → **ไม่สุ่มหมู่** เช่นกัน

## 4) ขั้นตอนที่ 1 — อัปโหลด Excel แผนเยี่ยมเยียน

ใช้ไฟล์ที่ **หัวหน้าส่งรายเดือน** (แผนเยี่ยมเยียนระดับบุคคล) ไม่ต้องแก้คอลัมน์เองถ้าหัวหน้าส่งตามรูปแบบมาตรฐาน

ตัวอย่างไฟล์จริงของ สนง.กษอ.สีดา: ชีตชื่อเดือน เช่น `สค69` / `ส.ค.69` ภายในไฟล์แผนรายเดือน

### 4.1 รูปแบบที่ระบบรองรับ

| รูปแบบ | สัญญาณในหัวตาราง | หมายเหตุ |
|--------|------------------|----------|
| **แผนเยี่ยมเยียนเต็ม (legacy)** | มีคอลัมน์ `เครื่องมือ` + `สถานที่` | ไฟล์ที่หัวหน้าส่งส่วนใหญ่เป็นแบบนี้ |
| **แผนย่อ (visit plan)** | มี `กิจกรรม` + `บุคคลเป้าหมาย`/`เป้าหมาย` และไม่มี `เครื่องมือ` | รูปแบบสั้นลง |

### 4.2 คอลัมน์ที่ระบบอ่าน (แบบเต็มที่หัวหน้าส่ง)

| คอลัมน์ | ความหมาย |
|---------|----------|
| สัปดาห์ / สัปดาห์ที่ | ใช้เป็นบริบท (ไม่บังคับต่อการกรอก) |
| **วัน เดือน ปี** | วันที่ทำกิจกรรม (รองรับเลขไทย + ช่วงวัน) |
| **กิจกรรม/งานที่ปฏิบัติ** | ชื่องาน / ประเภทกิจกรรม |
| เครื่องมือ / อุปกรณ์ / สื่อ | ใช้ช่วยจำแนกประเภทกิจกรรม |
| สถานที่ | ถ้าเป็น `ตำบล …` / ชื่อเครื่องมือ → ระบบจัดใหม่ตามพื้นที่รับผิดชอบ |
| **บุคคลเป้าหมาย** | ใช้คำนวณ **จำนวนคน** |
| ผู้ร่วม / ร่วมปฏิบัติ | ผู้ร่วมปฏิบัติงาน (เก็บในข้อมูลแถว) |
| หมายเหตุ | ข้อมูลเสริม |

ระบบจะหาแถวหัวตารางอัตโนมัติ (มักอยู่แถวที่ 3–4 ของชีต)

### 4.3 รูปแบบวันที่ที่รองรับ

ตัวอย่างที่อ่านได้:

- `๓ ส.ค. ๖๙` หรือ `3 ส.ค.69` → วันที่เดียว `03/08/2569`
- `๕-๗ ส.ค. ๖๙` → **ขยายเป็นหลายแถว** (`05`, `06`, `07` ส.ค. 2569)

รองรับทั้งเลขไทย (๐–๙) และเลขอารบิก · ชื่อเดือนย่อ เช่น ส.ค. / สค / สิงหา

### 4.4 จำนวนคนจากบุคคลเป้าหมาย

| ค่าใน Excel | จำนวนคนที่ระบบใส่ |
|-------------|-------------------|
| มีตัวเลข เช่น `15 ราย`, `เกษตรกร50 ราย` | ดึงตัวเลข (เช่น 15, 50) |
| `ทุกท่าน` / `ทุกคน` / `จนท` / `จนท.ทุกท่าน` | **7** |
| ว่าง / ไม่มีตัวเลข | 0 (แถวประชุมจันทร์ที่ไม่มีจำนวนจะถูกตั้งเป็น 7) |

### 4.5 ขั้นตอนอัปโหลด

1. ยืนยันพื้นที่รับผิดชอบให้เสร็จก่อน (ปุ่มวิเคราะห์จะยังกดไม่ได้ถ้ายังไม่ยืนยัน)
2. ลากไฟล์ `.xls` / `.xlsx` วางในกล่อง หรือคลิกเลือกไฟล์
3. (แนะนำ) เปิดตัวเลือก **「สุ่มหมู่/ตำบลในสถานที่ หลังวิเคราะห์ Excel」**
4. กด **「วิเคราะห์และโหลดตาราง」**
5. เลือกแผ่นงาน (ชีตชื่อเดือน เช่น `สค69`) ใน Step 2 ถ้ามีหลายเดือน

> ![ภาพหน้าจอ — อัปโหลด](../static/docs/shot-upload.png)  
> *วางภาพ Step อัปโหลด Excel ที่นี่*

## 5) กฎวันจันทร์ / ประชุมสำนักงาน

ตามแผนเยี่ยมเยียนของ สนง.กษอ.สีดา — ระบบคำนวณจากวันที่จริง (ไม่พึ่งข้อความใน Excel อย่างเดียว):

| เงื่อนไข | ผลลัพธ์ใน T&V |
|----------|----------------|
| เป็น **วันจันทร์** และเป็นจันทร์แรกของเดือน (วันที่ 1–7) | **DM** — ประชุมสำนักงานเกษตรอำเภอประจำเดือน (`activity_val = 13`) |
| เป็น **วันจันทร์** อื่นของเดือน | **WM** — ประชุมสำนักงานเกษตรอำเภอประจำสัปดาห์ (`activity_val = 14`) |
| ไม่ใช่วันจันทร์ | ไม่บังคับเป็นประชุมสำนักงาน — ถือเป็นงานภาคสนามตามกิจกรรม |

**ตัวอย่าง ส.ค. 2569 (ชีต `สค69`):**

| วันที่ | วัน | ผล |
|--------|-----|-----|
| 03/08/2569 | จันทร์แรก | **DM / 13** ที่สำนักงาน |
| 10, 17, 24, 31 ส.ค. 2569 | จันทร์อื่น | **WM / 14** ที่สำนักงาน |

**สถานที่วันจันทร์:** ใส่เฉพาะชื่อสำนักงานเท่านั้น เช่น  
`สำนักงานเกษตรอำเภอสีดา`  
**ไม่ใส่** หมู่ / ตำบล ในแถวประชุม

ถ้าจำนวนคนว่าง ระบบตั้งเป็น **7** สำหรับแถวประชุมสำนักงาน  
ถ้าแถววันอื่นไปชี้สถานที่เป็นชื่อสำนักงานโดยไม่ตั้งใจ ระบบจะเคลียร์ไว้ให้หน้าจอจัดสถานที่ภาคสนามใหม่

## 6) การสุ่มหมู่ในงานภาคสนาม (PD_PLACE)

ใช้กับแถวที่ **ไม่ใช่** ประชุมสำนักงานวันจันทร์

### 6.1 กฎตามพื้นที่รับผิดชอบ

| กรณี | พฤติกรรม |
|------|----------|
| รับผิดชอบ **1 ตำบล** | สุ่มหมู่ **2–4 หมู่** จากหมู่บ้านจริงของตำบลนั้นเท่านั้น |
| รับผิดชอบ **หลายตำบล** (ยังไม่ครบทั้งอำเภอ) | สุ่มหมู่ 2–4 ให้ **ทุกตำบลที่รับผิดชอบ** แล้วรวมในช่องสถานที่ |
| **ทุกตำบล** (หัวหน้า / ธุรการ / ติ๊กครบอำเภอ) | ใส่ชื่อตำบลทั้งหมด · **ไม่สุ่มหมู่** |

### 6.2 หมู่มาจากข้อมูลจริง

- ระบบโหลดหมู่บ้านจาก `data/villages/{รหัสตำบล}.json`
- ตัวอย่าง: ตำบล**หนองตาดใหญ่** มี **9 หมู่** (ม.1–ม.9) — ไม่ได้สุ่มจากเลขปลอม 1–20
- ถ้าตำบลใดยังไม่มีไฟล์หมู่บ้าน ระบบจะข้ามการสุ่มหมู่ตำบลนั้น (และแจ้งใน log)

### 6.3 รูปแบบ PD_PLACE

```
หมู่ 1, 3, 5 ตำบลหนองตาดใหญ่
```

หลายตำบล:

```
หมู่ 1, 3, 5 ตำบลหนองตาดใหญ่, หมู่ 2, 4 ตำบลสามเมือง
```

ประชุมสำนักงาน:

```
สำนักงานเกษตรอำเภอสีดา
```

สามารถแก้สถานที่ในตารางทีละแถวได้หลังโหลด ก่อนกดเริ่มกรอก

## 7) ขั้นตอนที่ 2 — บัญชี T&V และการตั้งค่า

### 7.1 บัญชีเข้าระบบ

| ช่อง | คำอธิบาย | การเก็บในเครื่อง |
|------|----------|------------------|
| ชื่อผู้ใช้งาน | บัญชี T&V ของท่านเอง (เช่น เลขบัตรประชาชน) | หน่วยความจำของแท็บเท่านั้น |
| รหัสผ่าน | รหัสผ่านของท่านเอง | หน่วยความจำของแท็บเท่านั้น — ล้างหลังจบการรัน |
| ผู้อนุมัติ | ชื่อในรายการ `USR_APPROVERS` ของพอร์ทัล | `localStorage` |

**สำคัญ**

- แต่ละคนใช้บัญชีของตนเอง — ระบบไม่มีบัญชีกลาง และไม่ hardcode รหัสผ่าน
- ถ้าไม่กรอกชื่อผู้ใช้หรือรหัสผ่าน เซิร์ฟเวอร์จะปฏิเสธการรัน

### 7.2 โหมดทำงาน

| โหมด | ความหมาย |
|------|----------|
| **Dry-run (ทดสอบ)** | กรอกในเบราว์เซอร์เพื่อตรวจทาน · ไม่กดบันทึกส่ง · ค้างหน้าต่างไว้ให้ดู ~3 นาที |
| **บันทึกชั่วคราว** | กด Save Draft บนพอร์ทัล |
| **บันทึก & ส่งข้อมูล** | บันทึกและส่งแผน (มีหน้าต่างยืนยันก่อนเริ่ม) |

ตัวเลือก **ซ่อนหน้าต่างเบราว์เซอร์ (Headless):**  
บน Windows สามารถเปิดให้เห็นหน้าต่างได้ (เอาเครื่องหมายออก) เพื่อเฝ้าดูการกรอก

## 8) ขั้นตอนที่ 3 — ตรวจทานตาราง

หลังวิเคราะห์ Excel จะเห็นตารางสรุป:

| คอลัมน์ | ตรวจอะไร |
|---------|----------|
| วันที่ | ตรงกับแผนหรือไม่ (ช่วงวันถูกขยายแล้วหรือยัง) |
| ประเด็นงาน / กิจกรรมหลัก | ประชุม WM/DM · เยี่ยมเยียน · อื่นๆ |
| รายละเอียด | ข้อความกิจกรรม |
| **สถานที่** | สำนักงาน (จันทร์) หรือ `หมู่ … ตำบล…` |
| จำนวนคน | จากบุคคลเป้าหมาย |
| สถานะ | ว่าง / กำลังกรอก / สำเร็จ / error ตอนรัน |

แนะนำให้ตรวจก่อนเริ่มรัน:

1. แถววันจันทร์ทั้งหมดเป็นประชุมที่สำนักงานหรือไม่
2. จันทร์แรกของเดือนเป็น **DM** หรือไม่
3. งานภาคสนามมีหมู่ที่สมเหตุสมผลหรือไม่
4. จำนวนคนไม่เป็น 0 โดยไม่ตั้งใจ

สามารถ **เพิ่มแถวใหม่** หรือแก้ค่าในตารางได้ก่อนเริ่มกรอก

> ![ภาพหน้าจอ — ตารางตรวจทาน](../static/docs/shot-table.png)  
> *วางภาพตารางสรุปที่นี่*

## 9) ขั้นตอนที่ 4 — เริ่มกรอกและดู Log

1. กรอกชื่อผู้ใช้ + รหัสผ่าน T&V ของท่าน
2. เลือกแผ่นงาน / ผู้อนุมัติ / โหมด
3. กด **「เริ่มกรอกข้อมูลเข้าระบบ T&V」**
4. ดู **Terminal Realtime Stream logs** ด้านล่าง  
   - เข้าสู่ระบบ  
   - เปิด Workflow 26 ทีละตำบล (กรณีหัวหน้า/ธุรการ)  
   - สถานะทีละแถว  
5. ถ้าแถวใดพลาด ระบบอาจแนบภาพหน้าจอ error ไว้ให้ดู

**ลำดับการกรอกบนพอร์ทัล (โดยย่อ):**  
ล็อกอิน → Workflow 26 → เลือกปี/เดือน/ตำบล → เพิ่มข้อมูลทีละแถว (ประเด็น, กิจกรรม, วันที่, รายละเอียด, สถานที่, จำนวนเป้าหมาย) → เลือกผู้อนุมัติ → บันทึกตามโหมดที่เลือก

บนเซิร์ฟเวอร์/เครื่องเดียวกันมักรันได้ทีละงาน (มีล็อกกัน Playwright ชนกัน) — ถ้าขึ้นข้อความว่ามีผู้อื่นกำลังรัน ให้รอแล้วลองใหม่

## 10) การประมวลผลข้อมูลแบบ Local Rules-Based

ระบบประมวลผล Excel ด้วย parser แบบ rules-based ภายในเครื่อง/เซิร์ฟเวอร์เท่านั้น และไม่มีการส่งข้อมูล Excel หรือ API key ไปยังบริการ AI ภายนอก. การจำแนกกิจกรรมใช้กฎคำสำคัญ ตารางรหัส Workflow 26 และกฎวันทำงานของระบบ.

## 11) คำถามที่พบบ่อย / ข้อควรระวัง

**ถาม: ทำไมอัปโหลดไม่ได้?**  
ตอบ: ยังไม่ได้กดยืนยันพื้นที่รับผิดชอบ หรือยังไม่ได้เลือกตำบลอย่างน้อย 1 ตำบล

**ถาม: ทำไมสถานที่เป็นแค่ชื่อตำบล ไม่มีหมู่?**  
ตอบ: เป็นโหมดหัวหน้า/ธุรการ (ทุกตำบล) หรือปิดตัวเลือกสุ่มหมู่ หรือตำบลนั้นยังไม่มีข้อมูลหมู่บ้านใน `data/villages/`

**ถาม: ชื่อตำบลต้องตรงกับพอร์ทัลไหม?**  
ตอบ: ต้องตรงกับรายการใน T&V (เช่น `หนองตาดใหญ่`) — ใช้พรีเซ็ตสีดาจะช่วยลดความผิดพลาด

**ถาม: รหัสผ่านหายไปทำไม?**  
ตอบ: ตั้งใจเก็บแค่ `sessionStorage` เพื่อความปลอดภัย — กรอกใหม่เมื่อเปิดเบราว์เซอร์ใหม่

**ถาม: ไฟล์ Excel ที่มีคอลัมน์เครื่องมือ/สถานที่ ใช้ได้ไหม?**  
ตอบ: ได้ — นี่คือรูปแบบหลักที่หัวหน้า สนง.กษอ.สีดา ส่งรายเดือน (เช่น ชีต `สค69`) ระบบอ่านอัตโนมัติ

**ถาม: หน้าจอไม่เปลี่ยนหลังอัปเดต?**  
ตอบ: กด **Ctrl+F5** เพื่อบังคับรีเฟรช (ไฟล์ CSS/JS ใช้ `?v=area3`)

### ข้อควรระวัง

- อย่าแชร์รหัสผ่าน T&V ในแชท ไฟล์ตั้งค่า หรือ Git
- ก่อนส่งจริง แนะนำ Dry-run อย่างน้อย 1 ครั้ง
- ตรวจชื่อผู้อนุมัติให้ตรงกับตัวเลือกในพอร์ทัล
- หลังอัปเดตระบบ กด **Ctrl+F5** ทุกครั้ง
