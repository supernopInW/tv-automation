# DOAE T&V Automation

ระบบช่วยนำ **แผนเยี่ยมเยียนรายเดือน (Excel)** ที่หัวหน้าส่ง เข้าสู่พอร์ทัล [DOAE T&V](https://tandv.doae.go.th) (Workflow 26) โดยอัตโนมัติ

ออกแบบให้เจ้าหน้าที่ สนง.กษอ. (เริ่มจาก **อำเภอสีดา จ.นครราชสีมา** และรองรับทุกอำเภอทั่วประเทศ) ตั้งค่าพื้นที่รับผิดชอบเป็นหน่วย **ตำบล** → อัปโหลดแผน/สุ่มสร้างแผนบนเว็บ → ตรวจทาน → กรอกด้วยบัญชี T&V ของตนเอง

---

## คุณสมบัติหลัก

- **พื้นที่รับผิดชอบก่อนอัปโหลด/สร้างแผน** — หน่วยเล็กสุดคือตำบล (ติ๊กได้หลายตำบล · กำหนดจำนวนสมาชิกสำนักงานได้)
- **บทบาท:** เจ้าหน้าที่ (1+ ตำบล) · เกษตรอำเภอ/หัวหน้า · ธุรการ (ไปกับหัวหน้า = ทุกตำบล)
- **กำหนดจำนวนสมาชิกสำนักงาน (คน):** อ้างอิงอัตโนมัติสำหรับเป้าหมายวันประชุมสำนักงาน (DM/WM)
- **อ่านแผนเยี่ยมเยียนที่หัวหน้าส่ง** (ชีตเดือน เช่น `สค69`) — คอลัมน์ สัปดาห์ / วันเดือนปี / กิจกรรม / เครื่องมือ / สถานที่ / บุคคลเป้าหมาย / ผู้ร่วม
- **สุ่มสร้างแผนงานบนเว็บ:** รองรับการเลือกเว้นวันหยุดประจำเดือน / วันหยุดนักขัตฤกษ์ไทย
- **ขยายช่วงวัน** เช่น `๕-๗ ส.ค. ๖๙` → หลายแถวอัตโนมัติ
- **วันจันทร์** = ประชุมที่ `สำนักงานเกษตรอำเภอ...`  
  - จันทร์แรกของเดือน (เช่น 03/08/2569) → **DM (13)**  
  - จันทร์อื่น → **WM (14)**
  - จำนวนเป้าหมายวันประชุม = อ้างอิงตามจำนวนสมาชิกสำนักงานที่ตั้งค่าไว้
- **งานภาคสนาม** สุ่มหมู่ 2–4 จากหมู่บ้านจริงตามจำนวนตำบลที่รับผิดชอบ + สุ่มจำนวนบุคคลเป้าหมายภาคสนามจาก `[20, 30, 50, 60]` คน
- รูปแบบสถานที่: `หมู่ 1, 3, 5 ตำบลหนองตาดใหญ่, หมู่ 2, 4 ตำบลสามเมือง`
- แต่ละคนล็อกอินด้วย **บัญชี T&V ของตนเอง** (รหัสผ่านเก็บแค่ `sessionStorage`)
- โหมด Dry-run / บันทึกชั่วคราว / บันทึก & ส่ง
- พรีเซ็ตด่วนอำเภอสีดา + ข้อมูลภูมิศาสตร์ทั้งประเทศในโฟลเดอร์ `data/`

## Quick Start (รันบนเครื่อง)

```bash
cd D:\จากไดรฟ์C\Downloads\tv_automation
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
python app.py
```

เปิดเบราว์เซอร์: **http://127.0.0.1:5000**

หลังแก้โค้ด/หน้าจอ กด **Ctrl+F5** เพื่อรีเฟรชแบบไม่ใช้แคช

> ครั้งแรกหรือเมื่อต้องการอัปเดตข้อมูลพื้นที่:  
> `python scripts/build_geo_data.py`  
> (โปรเจกต์มักมี `data/` พร้อมใช้อยู่แล้ว)

## ใช้งานเร็ว ๆ (5 ขั้น)

1. **พื้นที่รับผิดชอบ** — พรีเซ็ตสีดา · เลือกบทบาท · ติ๊กตำบล · กดยืนยัน  
2. **อัปโหลด Excel** แผนเยี่ยมเยียนที่หัวหน้าส่ง · กดวิเคราะห์  
3. **ตรวจตาราง** — จันทร์=สำนักงาน · วันอื่น=หมู่/ตำบล · จำนวนคน  
4. กรอก **บัญชี T&V ของท่าน** + ผู้อนุมัติ · เลือกโหมด (เริ่มจาก Dry-run)  
5. กดเริ่มกรอก แล้วดู log แบบ realtime

รายละเอียดเต็ม: **[docs/USER_GUIDE.md](docs/USER_GUIDE.md)**  
กระแสงานรายเดือน: **[docs/WORKFLOW.md](docs/WORKFLOW.md)**

## โครงสร้างสำคัญ

```

data/                  # ข้อมูลภูมิศาสตร์ + villages/*.json

static/app.js          # UI · สุ่มหมู่ · กฎวันจันทร์
docs/
  USER_GUIDE.md        # คู่มือผู้ใช้
  WORKFLOW.md          # Excel รายเดือน → T&V
  DEPLOY.md            # Deploy / build geo
requirements.txt
Dockerfile
```

## บัญชีและความปลอดภัย

| รายการ | พฤติกรรม |
|--------|----------|
| ชื่อผู้ใช้ T&V | จำในเครื่องได้ (`localStorage`) |
| รหัสผ่าน | เฉพาะเซสชัน (`sessionStorage`) — ไม่เก็บถาวร ไม่ hardcode |
| การรัน | ต้องมีทั้ง username + password ของผู้ใช้คนนั้น |

อย่าแชร์รหัสผ่านในแชท ไฟล์ตั้งค่า หรือ commit เข้า Git
